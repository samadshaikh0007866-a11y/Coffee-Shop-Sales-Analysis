# ☕ Coffee Shop Sales Analysis

An end-to-end data analytics project exploring coffee shop sales performance using Python and Power BI.

## 📌 Project Overview

Analyzed coffee shop transaction data to identify sales trends, product performance, and store-level performance.

## 🛠️ Tools & Technologies

- Python
- Pandas
- Google Colab
- Power BI
- DAX

## 📊 Key Analysis

- Monthly sales trends
- Sales by store location
- Product category performance
- Sales by transaction hour
- Key Performance Indicators (KPIs)

## 🔍 Key Insights

- June recorded the highest monthly sales.
- February recorded the lowest monthly sales.
- Hell's Kitchen was the top-performing store location.
- Coffee was the highest-selling product category.
- Packaged Chocolate was the lowest-selling category.
